# Hi, I'm José de Jesús 👋

**Robotics & Telecommunications Engineering Student @ UDLAP**

I build systems that connect code with the physical world. Instead of just writing software, I'm interested in how machines perceive their environment, learn from demonstrations, and navigate autonomously. Right now, my academic focus is on mixing classical control theory with modern continual learning.

---

### 🔭 What I'm currently doing

*   **Honors Research:** Integrating continual learning AI with classical control systems to create adaptive behaviors in autonomous robots.
*   **Torneo Mexicano de Robótica:** Writing navigation software in **ROS 2** (C++ & Python) and running Gazebo simulations for the AutoModelCar competition.
*   **Infrastructure:** Managing a self-hosted Debian Homelab environment using Docker containers to deploy and test my services.

### 🚀 Recent Milestones

*   Developed the iOS frontend for **ResiApp** (SwiftUI) during the Enactus National Hackathon (2026).
*   Received an **Honorable Mention** at the NASA Space Apps Challenge (2025).
